# Social tone experimental recipes

Three original experimental recipes for Film Studio. Import an individual JSON through Recipes → Import Recipe.

| File | Style |
| --- | --- |
| `soft-white.json` | Soft White |
| `cream-daylight.json` | Cream Daylight |
| `cafe-brown.json` | Cafe Brown |

These are early recipes using the existing film LUTs. Adjust exposure and white balance for each photo. Visual acceptance for a production collection is pending.
